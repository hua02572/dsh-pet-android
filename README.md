# dsh-pet-android 桌宠（安卓悬浮窗版）

用 dsh-pet 开源素材做的安卓悬浮窗桌宠。无 AI 功能：纯动画链 + 拖动 + 点击回应。

## 功能
- 悬浮窗透明宠物，常驻屏幕角落，可单指拖动
- 待机呼吸循环，播完按权重随机播其他动作（idle 10 / actions 5，与桌面版一致）
- 轻点宠物 → 随机播一个「点击回应」动画
- 90 个动画全部打包（45MB，来自 dsh-pet MIT 开源素材）

## 构建（不需要本地装 Android Studio）
1. 把本目录推送到 GitHub 仓库（含 `.github/workflows/android.yml`）
2. 仓库页 → Actions → `android-apk` → 等待构建完成
3. 在构建结果里下载 `dsh-pet-android-debug-apk`
4. 传到手机安装（允许安装未知来源应用）

## 使用
1. 打开 App，点「开启桌宠」
2. 首次会跳转系统「显示在其他应用上层」授权页，允许后返回再点一次
3. 宠物出现在屏幕左下角，拖动可移动，轻点有回应
4. 停止：通知栏点开 App → 「停止桌宠」，或系统设置里强行停止

## 已知限制
- 透明 webm 用 WebView + Canvas 绘制；个别老旧机型 WebView 不支持 VP9-alpha 时会显示黑底（可后续转 APNG 解决）
- 国产 ROM 省电策略可能杀后台；被杀后重新打开 App 点「开启桌宠」即可
- 拖动采用窗口位移，贴边吸附、多宠物、甩抛物理未实现（后续可加）
